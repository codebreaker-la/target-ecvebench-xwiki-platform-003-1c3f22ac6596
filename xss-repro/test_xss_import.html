GHSA-36fm-j33w-c25f — XSS Reproduction

This page reproduces the stored XSS vulnerability in XWiki's XAR import UI. The createPackageHeader function in import.js uses Prototype.js's .update() (which sets innerHTML) to render unsanitized XAR package metadata fields (name, version, author, licence, filename).

An attacker crafts a malicious XAR file with HTML/JS payloads in metadata fields. When an admin imports the package, the payloads execute in the admin's browser session.
